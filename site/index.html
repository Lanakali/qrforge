API documentation

Base URL: https://your-qrf-domain/api/v1 — replace with your deployment URL.

POST/api/v1/register — get a free API key

Returns a new API key on the Free plan (200 codes/month). JSON body is optional.

curl -X POST https://your-qrf-domain/api/v1/register \
  -H "Content-Type: application/json" \
  -d '{"name": "my-project"}'

→ 201
{"apiKey":"qrf_live_…","plan":"free","monthlyLimit":200}

GET/api/v1/qr — generate a QR code

Generate a PNG (default) or SVG QR code. Authenticate with the X-API-Key header (or key query param for plain <img> tags).

curl -G "https://your-qrf-domain/api/v1/qr" \
  -H "X-API-Key: qrf_live_…" \
  --data-urlencode "data=https://qrforge.dev" \
  --data "size=512&ec=H&format=png" \
  -o code.png
ParamRequiredDefaultDescription
datayes—Text or URL to encode (max 2000 chars).
sizeno300Pixel dimension, 1–2000.
formatnopngpng or svg.
ecnoMError correction: L (7%) M (15%) Q (25%) H (30%).
darkno#000000Foreground color, hex.
lightno#ffffffBackground color, hex (8-digit hex for alpha).
transparentno01 = transparent background (PNG).
marginno2Quiet-zone modules, 0–10.

Every successful response includes quota headers: X-Ratelimit-Limit, X-Ratelimit-Remaining, X-Ratelimit-Period.

POST/api/v1/qr — same, as JSON

Identical parameters in a JSON body, for environments where GET encoding is awkward.

curl -X POST https://your-qrf-domain/api/v1/qr \
  -H "X-API-Key: qrf_live_…" \
  -H "Content-Type: application/json" \
  -d '{"data":"https://qrforge.dev","size":512,"format":"svg","ec":"H"}'

GET/api/v1/usage — quota & plan info

StatusCodeMeaning

401unauthorizedMissing or invalid API key.

500internal_errorOur fault — retry or contact support.

Rate limits (per IP, abuse prevention)

/api/v1/qr: 120 req/min · /api/v1/register: 5/hour · demo endpoint: 20/min, 100/day. Monthly quotas are per API key, on top of these.
